The DUMP_HEADER64 struct, read directly from the first bytes of a dump file.

Layout reference: dbgeng.h / the Windows crash-dump format, as modelled by kdmp-parser. Every field is decoded from a fixed index of a fixed-size buffer, so there is no slicing, no expect, and no panic path in the parser.
