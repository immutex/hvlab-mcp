Plan tokens: digest-bound, single-use, expiring authorization for destructive and guest-execution operations.

A boolean confirm flag is not accepted anywhere in the API: a flag can be set once and reused, or globally neutered by an env var. A plan token is bound to the exact canonicalized arguments of one call, expires, and is consumed on use.
