pub struct Plan {
    pub id: PlanId,
    pub digest: [u8; 32],
    pub tool: String,
    pub target: Option<VmId>,
    pub steps: Vec<PlanStep>,
    pub expires_at: SystemTime,
    pub policy_revision: u64,
}
Expand description

A pending destructive operation awaiting authorization.

Fields§

§id: PlanId

Identifier for the plan.

§digest: [u8; 32]

SHA-256 over Plan::canonical_input. The token the caller must echo back is the first 32 hex chars of this.

§tool: String

Tool being authorized.

§target: Option<VmId>

Target VM, when the operation is per-VM.

§steps: Vec<PlanStep>

Steps for composites; single-operation plans have exactly one.

§expires_at: SystemTime

When this plan expires.

§policy_revision: u64

Policy revision at mint time. A policy change invalidates all outstanding plans.
